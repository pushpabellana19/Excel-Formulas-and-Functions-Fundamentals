# Excel Formulas & Functions Fundamentals

## Project Overview
This project demonstrates essential Excel formulas and functions using the Sample Superstore sales dataset. The goal is to practise common data analysis tasks using lookup functions, logical conditions, conditional calculations, and text manipulation.

## Dataset
- **Dataset:** Sample Superstore
- **Data used:** Order details, product information, region, sales, quantity, discount, and profit.

## Formulas Demonstrated

1. **VLOOKUP** — Finds a product name using its Product ID.
2. **XLOOKUP** — Searches for a Product ID and returns the matching product name.
3. **IF** — Classifies a transaction based on whether its profit is positive.
4. **SUMIFS** — Calculates total sales for the South region.
5. **COUNTIFS** — Counts transactions belonging to the South region.
6. **LEFT (Text Function)** — Extracts the first five characters of a product name.

## Key Results
- Successfully demonstrated six formula examples.
- Calculated South region sales using SUMIFS.
- Counted South region transactions using COUNTIFS.
- Compared VLOOKUP and XLOOKUP for product lookup.
- Added notes explaining when each formula is useful.
